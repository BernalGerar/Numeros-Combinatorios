# 📚 Mis Apuntes de Números Combinatorios y Coeficientes Multinomiales

Este proyecto reúne mis apuntes personales sobre números combinatorios y coeficientes multinomiales, transcritos cuidadosamente desde mis borradores a código **LaTeX**. 

En este repositorio encontrarás tanto el código fuente como el 
archivo PDF final compilado (disponible dentro de la carpeta `PDFs`).

---

## 🚧 Estado del Proyecto

Este documento se encuentra actualmente en **etapa de construcción**. Iré ampliando y profundizando el material progresivamente con nuevos teoremas, ejemplos y propiedades de la combinatoria. ¡Las sugerencias son bienvenidas!.
